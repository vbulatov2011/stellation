Examples

Stellations worth a second look. Each one is a saved document: click it and the app opens with that arrangement built and those cells chosen, ready to be pulled apart, added to, or saved somewhere of your own.

The gallery reads examples.json, which lists each document with its tags and a note. Adding one is three steps: save the document, drop the .json and its .json.png thumbnail into examples/, and add an entry to the catalog.
