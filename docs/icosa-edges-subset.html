The 59, with continuous edges

The canonical rules plus a ban on segmented edges — the harshest cut of the canonical list, leaving 25.

The rules

A cell set is accepted when all of these hold:

  1. No enantiomorphs
  2. No hidden cavities
  3. No separated shells
  4. No segmented edges
